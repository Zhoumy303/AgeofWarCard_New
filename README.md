## 项目简介

《纪元战争》是一款回合制卡牌战棋游戏。玩家在 5×7 的棋盘上放置单位、使用法术，通过移动、攻击、技能配合来摧毁敌方大本营。游戏内置基于规则和评分的 AI，支持人机对战、自动对弈和独立的简化对战模拟，并提供三个 BOSS 挑战关卡、可保存进度的剧情冒险，以及 WebSocket 双人联机原型。

---

## 功能特性

- **回合制战棋**：放置阶段 + 战斗阶段，行动点数、抽卡费用、手牌上限等完整规则。
- **多阵营单位**：人族、暗影族、兽灵魔族，每个单位拥有独特技能。
- **法术卡牌**：医疗包、护盾卡、抽卡牌、重置卡、寒冰新星等。
- **AI 对战**：可切换任意玩家为 AI，AI 会评估攻击、移动、技能、法术并做出决策。
- **AI 统计与策略**：记录人机对战胜率和近期对局，策略权重可导入/导出/重置；当前不进行强化学习或随机权重进化。
- **自动对弈**：双方 AI 自动进行多局对战，最多 100 局。
- **简化对战模拟**：多个独立实例运行，不修改主棋局、不计入真实胜率或策略学习。
- **BOSS 挑战**：暗影议会、冰霜女王、钢铁教父，每个 BOSS 拥有独特机制。
- **剧情模式**：三个角色、按难度递进的战斗、宝箱、岔路口、商店、泉水、酒馆、觉醒、道具和经验升级；支持继续游戏。
- **多人联机**：基于 WebSocket 的房间制联机，支持游戏状态同步和聊天。
- **玩家界面**：固定本人视角，默认隐藏对手手牌；常驻卡牌与单位详情、合法目标高亮、当前步骤提示、操作禁用原因、玩法帮助和取消选择。开发与模拟工具默认折叠。
- **工具提示**：卡牌、单位、大本营悬停显示详细信息。

## 快速开始

### 环境要求

- Node.js（本轮测试环境为 24.15.0；回归测试使用内置 `node:test`）
- 现代浏览器（Chrome / Edge / Firefox）
- 可选：`http-server`（全局安装）

### 1. 启动 WebSocket 服务器

```bash
cd card_game_server
npm install
node server.js
```

服务器默认监听 `3000` 端口，控制台输出：`服务器已启动，监听端口 3000`。

### 2. 启动静态文件服务器

在项目根目录执行：

```bash
npm install -g http-server
http-server -p 8080
```

### 3. 访问游戏

- 单机体验：`http://localhost:8080/game.html`
- 玩家 1：`http://localhost:8080/game.html?player=1&room=testroom`
- 玩家 2：`http://localhost:8080/game.html?player=2&room=testroom`

局域网联机时，将 `localhost` 换成运行静态服务器的机器 IP，例如：
`http://192.168.1.7:8080/game.html?player=1&room=testroom`

## 配置说明

### WebSocket 服务器地址

只有 URL 显式包含 `room` 时才连接服务器；不带 `room` 的单机模式不需要 WebSocket 服务。前端在 `js/constants/multiplayer.js` 中使用页面当前主机的 `3000` 端口：

```js
const protocol = window.location.protocol === 'https:' ? 'wss:' : 'ws:';
const host = window.location.hostname || 'localhost';
const wsUrl = `${protocol}//${host}:3000?room=${encodeURIComponent(roomId)}&player=${encodeURIComponent(playerId)}`;
```

本地 HTTP 页面连接 `ws://localhost:3000`。HTTPS 部署需要另行提供支持 TLS 的 WebSocket 服务或代理；附带服务器本身是 HTTP/WebSocket 服务。

### URL 参数

| 参数     | 说明                              | 示例       |
| -------- | --------------------------------- | ---------- |
| `room`   | 房间 ID，同一房间的玩家会同步状态 | `testroom` |
| `player` | 玩家编号，`1` 或 `2`              | `1`        |

### 端口

| 服务      | 默认端口 |
| --------- | -------- |
| WebSocket | `3000`   |
| 静态文件  | `8080`   |

### IIS Express（可选）

`applicationhost.config` 中配置了站点，但包含硬编码绝对路径：
`C:\Users\22626\Desktop\游戏设计\纪元战争网页版`
换机器后需要修改，或直接使用 `http-server` 替代。

## 游戏玩法

在主菜单选择“快速人机对战”即可开局。先点击手牌查看真实费用与能力，再点击高亮格子部署；准备好后点击“部署完成 · 开始战斗”，选择己方单位移动、攻击或使用技能。顶部提示会说明下一步操作，对手回合保持本人视角并锁定操作。

点击“取消选择”或按 Esc 可退出目标选择；“玩法帮助”说明基本流程。同名卡受到“暗影腐蚀”而费用不同时，界面会单独选中并消耗你点击的那一张，详情和悬停提示显示实际费用。

### 棋盘与目标

- 棋盘为 **5 行 × 7 列**。
- 双方大本营位于第 3 行第 1 列（玩家 1）和第 3 行第 7 列（玩家 2）。
- 将对方大本营生命值降至 0 即可获胜。

### 回合流程

1. **放置阶段**：消耗行动点数从手牌放置单位或使用法术。
2. **战斗阶段**：选择单位进行移动、攻击或使用技能。
3. **结束回合**：切换到对方回合，恢复行动点数、重置单位行动状态。

普通单位每回合移动或攻击二选一；暗影刺客可以移动后攻击。攻击距离按横纵格数之和计算，基地格不可部署或普通移动进入。

### 资源

- **行动点数（AP）**：体验模式双方首个回合各有 2 点，之后各自回合恢复 2 点、最多 6 点；剧情敌人按各自配置恢复并受上限限制。
- **付费抽牌**：每回合前两次各 1 AP，第三次起 2 AP；开局发牌和抽卡法术不增加这个计数。
- **基地生命**：体验模式双方 7 点；剧情角色初始 6 点。
- **金币**：胜利后获得，用于商店购买等（剧情模式）。
- **手牌上限**：7 张；满手时抽牌不生效、不扣抽牌 AP，抽卡法术最多补到 7 张。

### 单位与技能

| 阵营     | 单位     | 技能                                                    |
| -------- | -------- | ------------------------------------------------------- |
| 人族     | 盾兵     | 防御：停止行动一回合后减免每次攻击 2 点伤害             |
| 人族     | 弓箭手   | 精准射击：1/6 概率造成双倍伤害                          |
| 人族     | 刀兵     | 溅射：对目标周围敌方单位造成 1 点额外伤害               |
| 暗影族   | 暗影刺客 | 刺杀：移动后可攻击；敏捷：可向后移动                    |
| 暗影族   | 暗影法师 | 暗影移动：与 3 格内队友交换位置                         |
| 暗影族   | 暗影领主 | 侵蚀：击杀单位后叛变为己方满血单位，需献祭一名己方单位  |
| 兽灵魔族 | 狂暴狼   | 野性冲锋：目标前方无单位时击退并造成 1 点额外伤害       |
| 兽灵魔族 | 牛头战士 | 笨重：仅能向前移动；野性祝福：增加周围 1 格内单位攻击力 |
| 兽灵魔族 | 冰霜龙   | 冰霜：消耗 1 点充能冰冻目标 1 回合                      |

### 法术卡

| 法术     | 费用 | 效果                                    |
| -------- | ---- | --------------------------------------- |
| 医疗包   | 1    | 恢复己方单位 3 点生命（不可恢复大本营） |
| 护盾卡   | 2    | 给己方单位添加 1 点护盾（不可给大本营） |
| 抽卡牌   | 2    | 抽取最多 3 张卡牌，不超过手牌上限       |
| 重置卡   | 1    | 将己方单位移回手牌并重置状态            |
| 寒冰新星 | 3    | 冻结所有敌方单位 3 个行动回合（特殊敌人卡） |

## AI 系统

### 策略权重

AI 使用以下权重评估决策（攻击优先级初始 2.0，其余初始 1.0）：

- `attackPriority`：攻击优先级
- `moveTowardsEnemy`：向敌方移动
- `protectLowHealth`：保护低血量单位
- `aggressivePlacement`：激进放置
- `defensivePlacement`：防守放置
- `spellUsage`：法术使用
- `skillUsage`：技能使用
- `rageSkill`：狂暴技能
- `shadowMoveSkill`：暗影移动
- `erosionSkill`：侵蚀技能

### 对局统计

- 仅恰好一方由 AI 控制的已结束对局计入人机胜率；双方 AI 自弈不会被统计为 AI 100% 获胜。
- 保留最近 50 局历史，当前不自动调整权重，也没有经过验证的强化学习流程。
- 数据保存在 `localStorage` 的 `aiLearningData` 键中。
- 支持通过界面按钮 **导出 / 导入 / 重置 / 查看统计**。

### 自动对弈与简化模拟

- AI 托管开关、统计和模拟位于默认折叠的“开发与模拟工具”。展开此区域会显示双方手牌，方便调试。
- **自动对弈**：点击“开始自动对弈”，双方 AI 使用实际游戏规则连续对战，最多 100 局；单局过长会停止，不随意指定胜者。
- **简化对战模拟**：设置实例数（1~10），使用简化规则独立运行；每局最多 200 次回合切换，超时记为平局，不修改实际对局、胜率或策略。它的结果不能用来证明主游戏平衡。

## BOSS 机制

| BOSS     | 描述        | 特殊机制                                                     |
| -------- | ----------- | ------------------------------------------------------------ |
| 暗影议会 | 刺客型 BOSS | 每回合自动召唤 1 个低级暗影（不消耗 AP）；卡组仅暗影族；每回合仅恢复 1 AP；大本营血量 5 |
| 冰霜女王 | 控制型 BOSS | 冰冻领域：敌方单位移动后 30% 概率被冰冻；专属卡“寒冰新星”；每回合恢复 3 AP |
| 钢铁教父 | 增益型 BOSS | 只招募人族；齐心协力：每回合开始 1 格内每个人族单位提供 1 点攻击力；每回合恢复 3 AP；基地被毁后生成“反攻巨像” |

> 反攻巨像：基地被毁后生成，攻击力极高，会自动向玩家基地方向移动并攻击。

## 剧情/预览模式

- **主菜单**：快速人机对战 / 开始冒险 / 继续冒险。
- **角色选择**：铁壁卫士、暗影猎手、兽群冲锋，各自拥有可用的初始卡组；战斗开始时双方各抽 3 张。
- **战斗预览界面**：
  - 左侧显示卡牌详情、角色立绘、生命/AP/金币/经验条。
  - 右侧显示事件卡（最多 3 张）。
  - 事件类型：战斗、宝箱、岔路口、商店、泉水、酒馆、觉醒圣坛、军需官和贤者馈赠。战斗按 Lv1 至 Lv4 递进，非战斗事件的位置仍随机。
- **经验与升级**：
  - 升级所需经验：Lv1→2 需 2，Lv2→3 需 4，Lv3→4 需 7，Lv4→5 需 12，Lv5→6 需 21，Lv6 为 MAX。
  - 最大生命值随等级提升：6 / 6 / 7 / 9 / 11 / 14；觉醒增加的生命上限在升级后保留。
- **存档与继续**：在事件页保存检查点，保留角色、卡组、资源、道具和剩余事件。未结束的战斗不保存棋盘；刷新后继续会回到战前事件页。
- **道具**：时间沙漏可消耗以获得一次额外回合；幸运硬币仍为占位定义，当前不出售。

## 开发与扩展

### 添加新单位

在 `js/constants/units.js` 的 `unitDefinitions` 中添加：

```js
newUnit: {
    name: "新单位",
    type: "human", // human / shadow / beast
    health: 5,
    attackRange: 1,
    damage: 2,
    cost: 2,
    skills: ["技能描述"],
    desc: "单位描述",
    img: "图片地址"
}
```

同时将卡牌 key 加入 `cardPool`。

### 添加新法术

在 `spellDefinitions` 中添加，并在 `applySpellEffect` 中实现效果；AI 的法术入口共用这套结算规则。

### 添加新 BOSS

1. 在 `js/display/ui-manager.js` 的 `BOSSES` 数组中添加配置。
2. 在 `initDecks()` 中根据 `type` 设置专属卡组。
3. 在 `endTurn()`、`moveUnit()`、`attack()` 等位置添加特殊机制判定。

### 修改 AI 权重

在 `loadAILearningData()` 的默认数据中调整初始值，或通过界面导出后手动修改再导入。

## 测试

node tests/ws-smoke.cjs

WebSocket 烟测需要已安装 `card_game_server` 的依赖，并会自行启动、关闭本地测试服务器；运行前确保端口 `3000` 空闲。若本机 `node` 未加入 PATH，用 `& 'C:\Program Files\nodejs\node.exe'` 替换上述 `node`。
